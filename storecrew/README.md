# StoreCrew Live

Hosted demo of StoreCrew: a free-first Shopify storefront studio with seven practical workflows, four design presets, live preview and Shopify OS2.0 ZIP export. Optional read-only Shopify OAuth requires `SHOPIFY_API_KEY`, `SHOPIFY_API_SECRET`, `SESSION_SECRET` and `PUBLIC_URL` set in Render. Never automatically publish live themes. The full advanced source version is available separately as a download in ChatGPT.

Run: `npm start` (Node 20+). Render: start `node storecrew/server.mjs`, build `echo ready`, Free plan.
